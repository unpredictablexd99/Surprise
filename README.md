# Kajal Birthday Surprise 🎀

A small, mobile-friendly birthday surprise website.

## Deploy / update on Vercel
1. Upload the **entire project folder** to the GitHub repository (not only `index.html`).
2. Keep the `assets` folder alongside `index.html`; it contains the floating reaction images/videos.
3. In Vercel, open the existing project and choose **Deployments → Redeploy** after pushing the updated files to GitHub.
4. Open the deployed URL on your phone and test the gift and celebration button.

This is a static site. No build command or environment variables are required.
